# El Euro Listo — reels de finanzas personales

Contenido y herramientas de la cuenta de Instagram **@eleurolisto**.

- `PLAYBOOK.md` — la rutina de cada noche: crear 2 reels, pedir aprobación y publicarlos a las 13:30 y 20:30.
- `toolkit/` — motor de animación propio (`reelkit.py`), voces en español de España (`voces.py`), música original sintetizada (`music.py`) y `setup.sh`.
- `reels/` — un directorio por reel publicado o propuesto (`render.py`, `video.mp4`, `info.json`).
- `content/` — banco de ideas, reels en reserva y registro de publicaciones.

Los vídeos de `reels/` se sirven desde este repositorio público para que vidIQ pueda publicarlos.
